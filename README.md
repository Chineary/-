# 孔令鹏导师研究网站

仅整理孔令鹏（Lingpeng Kong）。按照本目录 `AGENTS.md` 的五步流程生成可追溯材料，并按 `网站搭建.md` 实现 React、TypeScript、Vite、ECharts 本地网站。

## 使用

本次本地地址：<http://127.0.0.1:5173/>。

重新启动：在此目录执行 `npm run dev`，打开终端显示的地址。首次安装依赖执行 `npm install`。

修改 CSV、研究报告或中文展示副本后，运行一条命令：

```sh
npm run data:update
```

然后刷新网页。该命令只重新校验和导入本地材料，不会重新抓取网络资料。CSV 是可手工维护的事实来源；`中文展示副本.json` 保存中文摘要概述和本地 PDF 映射。原始英文摘要保留在论文信息汇总表中。

## 页面

- 基础信息：中英文导师检索、院系/兴趣/招生筛选、教育与任职、公开来源和招生说明。
- 研究方向：年度篇数、主要主题、经历阶段、七章分析报告、可筛选和分页的论文目录、中文摘要与证据弹窗。
- 合作者：已核验身份名单、可切换的原始待核验署名、合作图、共同论文跳转、末位和通讯比例、五章合作分析及合作者论文简表。

## 明确保留的缺项

- Scholar访问失败，个人用户ID未确认；总引用、单篇引用和统计日期为“未获取”，没有用0或其他数据库数值替代。
- 学校目录返回403；名单与个人主页/CV的院系归属不一致，保留“待核验”。
- 招生页面为无日期常设说明，“1±1人/年”是通常规模，不能视为2026/27承诺名额或当前截止日期。
- 学位入学年月、部分任职边界、双单位署名阶段与部分学生去向存在缺项或冲突。报告不据此认定研究转向。
- 部分重点合作者缺少可确认的主页、历史身份或完整论文列表。未确认的共同一作和通讯标记不计入已确认角色统计。
- CCF目录请求被自动审批拦截，原因为“官方算力限制”；目录版本及期刊分区年度未核验，等级保留“未核验”。详情见 `来源/目录核验说明.md`。

具体论文问题集中在 `未完成事项.csv`；教育/任职问题在研究报告中；合作者非论文问题集中在合作者汇总中。

## 验证与维护

```sh
npm test
npm run build
node scripts/qa-browser.mjs
```

数据测试验证跨表关联、去重、缺失引用处理、角色比例分母、报告章节和中文副本。浏览器脚本需要本机Chrome和已运行的5173端口；使用独立临时配置，验证搜索、筛选、分页、论文详情、下载链接及1440/768/390像素布局。截图和检查结果保存在 `验收/`。

`scripts/generate-research.mjs` 从已保存来源与人工核验笔记重建研究文件。它会覆盖生成的CSV/报告，手工维护材料后请只用 `npm run data:update`。下载或抓取脚本不会自动绕过登录、反爬或审批限制。
